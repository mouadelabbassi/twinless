# TWINLESS — scientific gates before presentation work

**Gate 0 — event compliance / provenance**
- Confirm exact Official Rules in accepted account.
- New public repo, only event-era original project-specific code.
- Maintain dated build log and immutable benchmark settings.

**Gate 1 — deterministic foundation (Day 1)**
- [x] Small physics environment with wrong structural assumption.
- [x] Testable discrepancy and hypotheses.
- [x] At least one discriminating experiment and posterior update.
- [x] Reproducible tests and structured evidence artifact.
- [ ] Benchmark fixtures independent of one hand-designed scenario.

**Gate 2 — actual Meta-powered agent**
- [ ] Validated Muse Spark API call using environment key.
- [ ] Structured hypothesis/action JSON with schema checks.
- [ ] Restricted tool registry (observe/predict/probe); no arbitrary shell.
- [ ] Agent can recover from invalid tool suggestions.
- [ ] Log prompts and tool inputs without logging any credentials.

**Gate 3 — scientific evidence**
- [ ] At least two topology families, held-out random seeds.
- [ ] Compare fixed policy, deterministic information-seeking policy,
      and Meta-agent policy under same observation/tool budget.
- [ ] Record success, false positives, probe cost, latency and failures.
- [ ] Independent verifier + abstain option when unidentifiable.

**Gate 4 — practical product**
- [ ] A complete model-repair and recommended action workflow.
- [ ] Explain evidence, uncertainties, and constraints.
- [ ] Interactive web app not centered on a dashboard.
- [ ] Public repo + three-minute *actual product* demo.

**No claimed first-place readiness until Gates 2–4 are validated.**
